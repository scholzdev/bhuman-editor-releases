# B-Human Editor

Releases of the B-Human Editor, a native macOS IDE for the B-Human code. This repository holds the disk images and the update feed. It holds no source code.

## Install

You need macOS 27 and Xcode 27.

1. Download the newest disk image from [Releases](https://github.com/scholzdev/bhuman-editor-releases/releases).
2. Open it and drag B-Human Editor to Applications.
3. Open the app. macOS blocks the first launch because the app is not notarized.
4. Open System Settings, then Privacy & Security, and click Open Anyway.

The app then updates itself. The release notes of every build are on the Releases page.
